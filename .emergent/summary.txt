<product_requirements>
The OTT Linker is a mobile-first application with a coral/mint/charcoal theme, featuring a hero carousel, responsive content trays, interactive tiles, and an AI orb (Bro). Key pages include:
- **Watch On:** A unified hub for OTT platforms, displaying platform-specific content in 1x6 horizontal scrolls with text-only capsules and tooltips. Tiles should be responsive (approx. 3 on mobile, 6 on desktop).
- **Buzz Meter:** A social pulse page with a consistent header, platform filters, a Trending Right Now grid, and a From the Feeds 1x6 tray. Tiles include a Buzz Score.
- **Entertainment:** A mood-and-genre-led discovery hub featuring a header, 6 mood/genre capsules (2x3 grid), and 4 content trays (1x6 horizontal scroll) using TMDB images.
- **Bro AI Agent (v1A):** A rule-based, friendly in-app guide with a floating icon, overlay (7 chips), header microlines, XP counter, and Buzz Moments.
- **Game On Module (v1A):** A sports discovery page with a two-tier header (Primary: LIVE, Cricket; Secondary: specific leagues), a Spotlight hero for tournaments/leagues, and multiple content trays: LIVE, TODAY, BIG MOMENTS (viral clips), COMING UP, HIGHLIGHTS, BEST OF. Automated descriptors are required for tiles.
- **Deep Linking:** Crucially, user clicks on titles should directly open the specific show page within the native OTT app, or redirect to the app store if not installed. The target behavior is similar to Prime Video, where a search tab opens with the show title image prominently displayed.
- **Search and Catalog:** The application needs a comprehensive catalog listing to support the existing search icon, the Bro AI agent, and dynamic trays across all sections (entertainment, watch on, game on). The catalog needs to expand significantly beyond the initial 20 titles.
