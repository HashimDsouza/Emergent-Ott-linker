<product_requirements>
The user wants The Connector, a prototype app for the Indian market, to connect users across OTT platforms (Netflix, JioHotstar, Prime, Apple TV, SonyLIV, MX, Lionsgate Play, Fancode, DAZN, etc.). It should inform users of the latest content (movies, series, sports, docus, reality) by providing:
1.  **What to watch:** Hot new content launches (Buzzing Now, Hot Drop Alert).
2.  **Where to watch:** Which OTT platform it's available on.
3.  **Why to watch:** IMDb ratings and direct links to social media (YouTube for trailers, X for trending, Reddit for discussions).
The app requires an AI agent for user guidance and personalized recommendations (initially fun, friendly, tongue-in-cheek). The design should be simple, clean, easy to use, visually trending, focused on vertical scrolls, and expert/authoritative, aiming to reduce user indecisiveness. Each content category will display 6 tiles in a 3x2 grid, with a See More option. A landing page with Sports/OTT/Music tabs, a hero carousel (5 scrollable launches), and a bottom navigation (Home, Genres, AI Agent, Explore, Me) is required. Gamification features including points for likes/shares, a global/content-specific community chat, a leaderboard (Your Tribe), and basic user profiles with badges are also requested. The core challenge in the current phase is to implement robust deep linking, allowing users to click a tile and be directed precisely to the show's page within the respective OTT app, with graceful fallbacks.
</product_requirements>
